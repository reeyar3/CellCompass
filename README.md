# CellCompass

CellCompass is an iOS app designed to help people newly diagnosed
with sickle cell disease navigate next steps, explore treatment
information, organize personal tools, and find community resources.

Built with Swift and SwiftUI in Xcode.

To run:
Download the project, open the .xcodeproj file in Xcode,
and run it on an iOS Simulator or compatible iPhone.

This app provides educational information and does not replace
professional medical advice.
